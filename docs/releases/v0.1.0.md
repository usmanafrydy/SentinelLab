# SentinelLab v0.1.0 local portfolio prototype

Final release checkpoint for the bounded local learning project, 5 October 2026. Preparation and final tests were performed on October 4; publication was continued on October 5. This completes the implemented portfolio scope ahead of the October 17 target. It is not production security certification. The earlier v0.1.0-rc.1 remains a separate historical pre-release; its tag must not be moved.

## Included workflow

Import bounded JSONL login events, validate fields, normalize UTC timestamps and retain original accepted text. Search SQLite records; repeated identical events are deduplicated and identity conflicts preserve the first original. Explicitly run R1 repeated account failures, R2 failures across distinct accounts and R3 success after earlier failures. Save explained alerts and run history without duplicating unchanged findings.

Sign in with a local account, create investigations, append notes, record reasoned decisions with revision checks and export complete saved JSON/Markdown reports. The four browser workspaces, synthetic samples, twelve-scenario evaluation, demo screenshots, case study, presentation guide and cumulative handbook support learning and portfolio review.

## Disposition of remaining qualifications

The owner chose to skip repeated hands-on exercises, and presentation practice is optional. One response correctly prioritised checking supporting evidence before deciding a case; no complete presentation or broad proficiency assessment is claimed. Optional practice does not block this release.

Word content/structure is checked, but visual pagination remains unverified while supported bundled LibreOffice is unavailable. The Markdown companion provides the current text. This is a retained documentation limitation, not a claim that a visual check passed.

The original laptop Git HEAD/index remain behind under existing access restrictions. Connector publication verifies all source files and the release target separately; it does not repair local Git history. Existing access controls are preserved.

This remains a single-account loopback HTTP learning prototype: no live collector, public hosting, multi-role platform or independent security audit. Alerts are investigation leads, not confirmed incidents. Authored synthetic metrics are not real-world accuracy. Local filesystem access can alter history. Reports have no signatures, encryption or automatic redaction; unsaved drafts are excluded. Private records and credentials are not release assets.

Future changes should be reviewed, checked, documented and released under a new version. Public hosting, live collection and stronger evidence integrity require separate design work. No external CV submission or job application is part of this release.
