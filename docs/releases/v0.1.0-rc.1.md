## Known limitations and final release conditions

- Single-account loopback HTTP prototype, not a public service, live collector, production SIEM or independently audited security product.
- Alerts identify patterns, not confirmed compromise. Authored synthetic evaluation is not real-world accuracy.
- Local filesystem access can alter database history. Reports have no signature, encryption or automatic redaction. Browser drafts are not saved until explicitly submitted.
- Word content is preserved, but visual pagination remains unverified because supported bundled LibreOffice is unavailable. The Markdown handbook is readable.
- The original laptop checkout retains restricted local Git HEAD/index metadata. Published files are verified through the connector; this does not synchronize that local history. Source ZIP acquisition was tested; git clone and other operating systems were not.
- Owner presentation practice is in progress. No completed rehearsal or understanding score is claimed until the owner actually demonstrates it. Final stable release remains pending that review and explicit treatment of remaining limitations.

This is a substantially AI-assisted learning project. Describe the learner's actual understanding and role honestly. No private accounts, real logs, generated private reports or runtime databases are release assets. Future fixes should receive a new version; do not silently move a published tag.
